# Support Resolution

Purpose: stabilize support or service issues and keep SLA-sensitive cases moving.

When to activate:
- support tickets
- escalation flows
- customer issue followthrough

Preferred strategies:
- inspect business state for customer impact
- prefer updating case state before escalation
- switch tool if the first path fails

Anti-patterns:
- escalating immediately without a concrete next step
- closing unresolved support cases

Completion checklist:
- case state updated
- next action or escalation recorded
