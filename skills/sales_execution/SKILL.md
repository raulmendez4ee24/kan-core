# sales_execution

Purpose: move a sales opportunity forward using the smallest useful action.

Activate when:
- the case is `sales_execution`
- a lead needs qualification or follow-up
- a high-value deal needs tighter handling

Preferred strategies:
- `qualify_lead`
- `close_followup`
- `executive_followup`

Avoid:
- over-escalating low-signal leads
- invoking other agents directly

Completion checklist:
- choose the next best sales move
- execute with allowed tools only
- return a concrete status and actions taken
