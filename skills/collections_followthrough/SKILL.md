# Collections Followthrough

Purpose: move overdue balances toward resolution with controlled follow-up.

When to activate:
- past due balances
- collections queue processing
- agreement or reminder workflows

Preferred strategies:
- prioritize highest exposure first
- keep messages auditable
- avoid repeating the same reminder loop without context change

Common mistakes:
- contacting low-value cases before high-risk ones
- ignoring existing agreements

Completion checklist:
- next collections action queued
- agreement context preserved
- case remains traceable
